## 📖 About

PopPlay is a fully functional OTT (Over-The-Top) streaming platform developed as a complete full-stack web application. It supports user authentication, profile management, video streaming, and a powerful admin dashboard for complete content and user management — all delivered through a clean JSP-based frontend backed by a robust Spring Boot REST architecture and a MySQL database.

---
## 🏗️ Tech Stack

| Layer | Technology |
|---|---|
| **Backend** | Java, Spring Boot |
| **Frontend** | JSP, HTML, CSS, JavaScript |
| **Database** | MySQL |
| **Build Tool** | Maven |
| **Server** | Apache Tomcat (Embedded) |
| **ORM** | Spring Data JPA / Hibernate |

---



## ✨ Features

### 👤 User Side
- 🔐 **User Authentication** — Secure Register / Login / Logout with session management
- 🎭 **Profile Management** — Users can view and update their personal profiles
- 🎥 **Video Streaming** — Browse and stream movies/shows directly in the browser
- 🔍 **Content Discovery** — Explore the full movie and media library

### 🛠️ Admin Side
- 📊 **Admin Dashboard** — Centralized control panel for platform management
- 🎬 **Movie Management (Full CRUD)** — Add, update, and delete movies/content
- 👥 **User Management (Full CRUD)** — View, update, and remove registered users
